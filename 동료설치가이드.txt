================================================
  재고관리 시스템 - 동료 설치 가이드
================================================

[최초 설치 - 한 번만 하면 됩니다]

1. 아래 링크에서 최신 재고관리시스템.exe 다운로드:
   https://github.com/SEUNGJUNHWANG/inventory-management/releases/latest

2. 원하는 폴더에 exe 파일 저장
   (예: C:\재고관리시스템\재고관리시스템.exe)

3. 승준님께 받은 API 키 파일(.json)을 같은 폴더에 저장

4. 프로그램 실행 → 왼쪽 메뉴에서 [⚙️ 설정] 클릭

5. 설정 화면에서:
   - [JSON 키 파일 선택] → API 키 파일(.json) 선택
   - [구글 시트 URL] → 승준님께 받은 URL 붙여넣기
   - [연결 테스트] 클릭 → "연결 성공!" 확인
   - [저장] 클릭

6. 완료! 이후부터는 그냥 exe 파일 실행만 하면 됩니다.

------------------------------------------------

[업데이트 - 자동으로 됩니다]

  "새 버전 v2.x.x 이(가) 출시되었습니다!
   지금 업데이트하시겠습니까?"

→ [예] 클릭하면 자동 다운로드 → 자동 교체 → 자동 재시작

별도로 파일을 받거나 설치할 필요가 없습니다.
